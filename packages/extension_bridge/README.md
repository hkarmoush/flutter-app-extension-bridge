# `extension_bridge`

Pure-Dart FFI runtime for cross-process Darwin App Extension communication, `<notify.h>` 64-bit kernel state registers, `0xdead10cc`-proof lock-free atomic snapshots, and Maildir queues with APFS `clonefile(2)` zero-copy attachments.

See the [Schema DSL Reference](https://github.com/hkarmoush/flutter-app-extension-bridge/blob/main/doc/reference/schema-dsl-reference.md) and [Contributing Guide](https://github.com/hkarmoush/flutter-app-extension-bridge/blob/main/CONTRIBUTING.md) for architecture and usage details.
